# Traffic Untangle

A hyper-casual "traffic jam" puzzle built in Flutter, in the style of Bus
Traffic Fever / Parking Jam. Tap a car to drive it off the grid — it only
moves if its lane to the edge is clear. Clear every vehicle before the
timer runs out to advance to a harder, procedurally generated level.

Every level is generated by `lib/logic/level_generator.dart`, which places
vehicles randomly and then mathematically proves the level is solvable
(via a dependency-graph / topological-sort check) before showing it to the
player — so you'll never hit an impossible board.

## Important: why there's no `android/` or `ios/` folder here

This project was written in a sandboxed environment with no access to
Google's servers (`storage.googleapis.com`, `dl.google.com`, `pub.dev`'s
package hosting, etc.), which is where the actual Flutter engine binaries
and Android SDK live. That means the Flutter/Android toolchains couldn't
be installed there to run `flutter create`, `flutter pub get`, or
`flutter build apk` — only the Dart/Flutter *source code* in `lib/` could
be written and hand-checked.

You have two easy ways to turn this into a real, installable APK:

### Option A — Let GitHub build it for you (no install needed)

1. Create a new GitHub repo and push this folder to it.
2. GitHub Actions will automatically run (see
   `.github/workflows/build-apk.yml`) and produce `app-release.apk`.
3. Go to the repo's **Actions** tab → the latest run → download the
   `traffic-untangle-apk` artifact, unzip it, and you have your APK.
4. To install it: copy `app-release.apk` to your Android phone, open it,
   and allow "install from unknown sources" if prompted.

You can also trigger it manually anytime from the Actions tab
("Run workflow").

### Option B — Build it yourself locally

1. Install Flutter: https://docs.flutter.dev/get-started/install
2. In this folder, run:
   ```
   flutter create --platforms=android,ios --project-name traffic_untangle --org com.abdulmajeed.trafficuntangle .
   flutter pub get
   flutter run            # test it live on a connected phone/emulator
   flutter build apk --release   # produces build/app/outputs/flutter-apk/app-release.apk
   ```
   (`flutter create` on an existing project only fills in the missing
   `android/`/`ios/` folders — it won't touch `lib/` or `pubspec.yaml`.)

## Before submitting to the Play Store / App Store

This is a solid, testable prototype, not yet a store submission. Before
publishing for real you'll still want to:

- Replace the placeholder `com.abdulmajeed.trafficuntangle` application ID
  if you want a different one, and set a real app icon (`flutter_launcher_icons`
  package makes this one command).
- Add a proper signing key for Android (`key.jks` + `key.properties`) —
  Play Store release builds must be signed, not the debug key.
- Test on a handful of real screen sizes; the board layout is responsive
  but hyper-casual reviewers are picky about first-3-seconds feel.
- Add real sound effects/music if you want more than the built-in
  system click + haptics used here (kept dependency-free for now).
- Decide on monetization (ads via `google_mobile_ads`, or none for a pure
  test) before you submit — the current build has no ad integration.
- For iOS, you'll need a Mac + Xcode + an Apple Developer account to build
  and submit — GitHub Actions can also do this via a `macos-latest`
  runner if you want, just ask and it can be added to the workflow.

## Project structure

```
lib/
  main.dart                    - app entry point
  models/vehicle.dart          - Vehicle data model
  logic/level_generator.dart   - procedural, solvability-guaranteed levels
  logic/game_state.dart        - timer, tap handling, win/lose logic
  logic/progress_storage.dart  - saves best level reached
  screens/home_screen.dart
  screens/game_screen.dart
  widgets/grid_board.dart       - renders the grid + animates exits
  widgets/vehicle_tile.dart     - a single car/bus tile + shake feedback
```
